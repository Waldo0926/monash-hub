## 来源和身份

来源目录扩展为 60 个明确的课程入口：本科/研究生官方学费表链接的 52 个唯一课程页，加上工程学院目录的 8 个具体学位页。心理咨询的既有停招通知来源单独保留。只登记 HTML 页面，不抓图片、PDF 或其他二进制材料，不自动追踪整个网站。

“已登记”“已抓取”“来源仍有效”“有明确申请通知”是不同状态。目录不复制价格或页面正文，也不代表 60 个页面都已抓取、都在开设或都开放申请。

清洗器保留链接所属表头/正文/表尾、行、列与锚文本，保持 rowspan/colspan 定位；原有表格纯文本和 Policy Bank 链接索引仍保留。学费解析器据此保留课程 URL。

旧索引没有单元格元数据时，仅对单课程行、完整行标签精确匹配且目的地唯一的链接做兼容读取；多学位共用行不猜测各个学位的来源。目录按课程名和学院匹配，同名 PhD/MPhil 不混用其他学院的课程页。

招生状态还要求索引中课程页的标题与该课程独立匹配。Handbook 代码只从唯一明确的 Handbook 课程链接读取，不确定则留空。非马来西亚或校区未知的 Handbook 记录不能继承马来西亚招生通知。

## 展示和判断

学费、当前申请通知、未来批次开放与个人资格保持独立。只有完整、明确且限定课程的通知才判定开放、关闭或暂停；按钮、截止日期及学费表不能代替通知。旧状态失效、来源失败、需登录、身份不匹配或超过 30 天时回到未核实。

API 和页面显示全部收费行的链接覆盖数、有效来源索引数、明确通知数和冲突数。`programme_page_verified` 只表示匹配来源索引仍有效，不表示开放申请。
