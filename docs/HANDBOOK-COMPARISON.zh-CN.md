# Handbook 单元年份对照：证据与限制

关联 #262。更新于 2026-11-03；评审和部署前属于 PR 实现，不是线上验收结论。

原功能已有明确年份选择、嵌套先修/同修/禁修、校区与学期、考核权重、未知考试状态、来源链接与核对时间。缺失年份不推断为停开，AND/OR 等价换序也不扁平化规则。

本次补上两处缺陷：

1. 改变选项曾直接改变旧结果标题，却未重读数据。结果现在保留实际请求的课号和年份；选项变更提示待更新，防止重叠请求，拒绝返回错误课号或年份的 API 快照。
2. API 把关系集合缺失统一输出为空列表，旧索引无法证明源中明确为空。只有可展示的非空数据，或解析器保留的明确源集合证据，才判断相同/新增/移除；旧空记录继续显示无法比较，等正常刷新提供证据。

解析器只在既有 UnitVersion JSON 中记录规范化布尔标记，不保存源 HTML，不需要数据库迁移。此标记不参与语义内容哈希；内容不变的正常刷新只补充相应版本的元数据，不重写子记录、不使翻译过期、不新增政策变更事件。

中英文保留 Handbook 原文和核对时间；增加纯解析测试、PostgreSQL 持久化/API 测试及桌面/手机回归。单元的年份不代替入学年份适用的学位规则，页面链接到现有课程图；课程图仍分别读取计划起始年的学位要求与实际修读年的单元信息。本单元页没有实现学位/AOS 整体要求对照，也不新增资格判断、交换学分映射或 AI 政策解释。

上线前仍需 CI、合并部署、自然刷新的源覆盖元数据和真实用户流程验收，再决定能否关闭 #262。本地跳过的 PostgreSQL 测试不能算通过；本次不强制重抓、不删除数据、不新建调度器。
