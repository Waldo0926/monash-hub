# 中文界面文案规范（Monash Hub）

适用范围：网站自身的按钮、菜单、提示、首页、社区、费用和规划工具。**不适用**于官方政策原文、Handbook数据、用户发布的内容和需要忠实翻译的官方资料。

## 原则

1. 先回答用户要做什么、下一步是什么。不写“赋能”“一站式”“智能化体验”“为您提供”等宣传套话。
2. 菜单、按钮、卡片标题和简短状态说明不加句末句号；帮助文档和连续叙述保留正常标点。**不要全站删除标点**。
3. 中文和英文、数字之间不额外加空格，例如`查看FIT2102的先修课`、`2027年学费`、`4MB以内`。英文单词之间正常保留空格。
4. 报错要说清楚发生了什么、用户能做什么，不要只写“操作失败”。
5. 用自然的学生语言，但术语必须准确：unit是单门课程，course是学位/课程项目，census date、hurdle、WAM、CGPA等按官方定义解释。
6. 不使用夸大承诺。来源陈述、翻译方式、更新时间、校区适用性必须与实际代码和数据一致。
7. 文案里的具体人数、测试数量、学费和语言支持可能过期；注明基准日期或改用动态数据。
8. 把`Monash官方资料`、`自动翻译`、`学生经验`显著区分，不能把站内推断当作官方批准。

## 改写示例

| 不推荐 | 推荐 |
| --- | --- |
| 登录没有走完。可以再试一次，或者用邮箱和密码登录 | 登录失败，请重试，也可以改用邮箱和密码 |
| 这是其他同学唯一能看到的信息。你的邮箱不会公开 | 其他同学只会看到你的昵称，不会看到邮箱 |
| 已从截图读取。截图识别可能出错，看总分之前请逐行核对 | 已识别截图，请核对课程和分数后再计算 |
| 我们致力于打造全面的学习服务平台 | 查课程、排学位计划、算WAM，或直接找官网原文 |

## 修改时检查

- 页面里不只有`frontend/i18n/index.ts`：`frontend/pages/*.vue`和组件中也有文案
- 同一状态在不同页面表达一致，空状态应给出可用的下一步
- 中文和英文都要实际渲染检查：手机宽度、长课程名、动态插值和错误信息
- 不要自动修改外部引用、用户输入、源码示例、URL、命令和官方翻译
- 语言下拉目前只有English与简体中文；旧的ja/ko翻译表并不代表仍支持这两种语言
